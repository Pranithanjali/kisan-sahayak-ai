The application is working very well overall, but I found one important usability issue that I would like to improve.

1. Maintain Conversational Context for Image Analysis (Highest Priority)

Currently, when I upload an image and ask a question such as:

"What flower is this?"

the AI correctly identifies the flower and provides useful information.

However, if I ask a follow-up question such as:

"How long does it take to grow?"
"Can it be grown indoors?"
"How often should I water it?"
"Which fertilizer is suitable?"

the AI forgets that I am referring to the previously uploaded image and instead gives a generic answer.

Please improve the conversation memory.

Requirements:

Remember the most recently uploaded image during the conversation.
Treat follow-up questions as referring to that image unless the user clearly changes the topic.
Preserve both the image context and the chat history.
Allow multiple follow-up questions without requiring the user to upload the same image again.
If the user uploads a new image, automatically switch the context to the new image.
If the user starts a completely different topic, reset the image context appropriately.
If the AI is unsure which image the user is referring to, politely ask for clarification instead of guessing.

The goal is to make the image conversation behave naturally, similar to modern AI assistants.

2. Improve Voice Input Reliability

Although the microphone interface has been improved, voice recognition is still unreliable during my testing.

Please verify the complete workflow end-to-end.

Ensure that:

The microphone actually captures speech.
Spoken words are converted into text.
The recognized text appears in the input box.
The user can edit the recognized text before sending.
The message is sent correctly.
Helpful error messages are shown if speech recognition fails.

Please test this thoroughly on supported browsers and mobile devices.

3. Final Testing

After implementing these improvements, perform a complete end-to-end test to ensure that image conversations, voice input, AI responses, and all existing features continue to work correctly.
